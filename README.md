# Comparador de números

Este proyecto es un ejercicio de lógica de programación realizado con JavaScript.

El programa permite ingresar tres números y compararlos para identificar cuál es el mayor, cuál es el menor y cuál corresponde al número del medio.

## ¿Qué hace el programa?

El programa permite:

* Ingresar tres números.
* Identificar el número mayor.
* Identificar el número menor.
* Identificar el número del medio.
* Mostrar los números de mayor a menor.
* Mostrar los números de menor a mayor.
* Detectar si los tres números son iguales.
* Detectar si hay dos números iguales.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

## ¿Cómo funciona?

El usuario ingresa tres números en los campos de la página y presiona el botón **"Comparar números"**.

El programa realiza las comparaciones necesarias y muestra los resultados en pantalla.

Para encontrar el número del medio se utiliza la suma de los tres números y se restan el mayor y el menor.

## Ejemplos

### Tres números diferentes

```text
Entrada:
8
5
2

Mayor a menor:
8, 5, 2

Menor a mayor:
2, 5, 8
```

### Dos números iguales

```text
Entrada:
4
4
2

Mayor a menor:
4, 4, 2

Menor a mayor:
2, 4, 4

Resultado:
Hay dos números iguales
```

### Los tres números iguales

```text
Entrada:
4
4
4

Resultado:
Los tres números son iguales
```
